# 求人票チェッカー

求人票に書かれた内容を入力すると、実質時給・年間休日・残業条件を計算し、業種相場と最低賃金の両面から採点するツールです。

**公開URL: https://shibazuke0707-beep.github.io/kyujinhyo-checker/**

年収の額面だけを見ても、時間あたりいくら稼げるのか、休みが実際どれだけあるのかは分かりません。固定残業代が月給に含まれていたり、賞与の金額が書かれていなかったりすると、なおさら比較が難しくなります。このツールは、そうした「書かれていること」と「書かれていないこと」を機械的に整理して、点数の形で見えるようにします。

## できること

- 年収一括入力と月給+賞与入力のどちらにも対応
- 固定残業代を差し引いた実質時給の算出
- 手当は12種類のプリセットから選択でき、それ以外は名称と性質を指定して自由に追加できます
- 毎月かならず同じ額が支給される手当のみを賃金に算入(金額不明の手当は情報開示の問題として減点)
- 47都道府県 × 15業種の相場との比較
- 都道府県別最低賃金を下回っていないかの判定
- 所定労働時間が法定労働時間を超えていないかの判定
- 100点満点(減点式)での採点と、カテゴリ別の内訳表示

## 入力内容は送信されません

このツールはHTMLファイル1つで動作し、入力内容を受け取るサーバーもデータベースもありません。給与額を含むすべての入力はブラウザ内で処理され、外部に送信も保存もされません。

詳細は[プライバシーポリシー](https://shibazuke0707-beep.github.io/kyujinhyo-checker/privacy.html)をご覧ください。

## 採点の仕組み

100点満点の減点式で、4つのカテゴリに配点しています。

| カテゴリ | 配点 | 主な評価対象 |
|---|---|---|
| 情報開示の透明性 | 20点 | 年収のみの記載、賞与や手当の金額不記載、固定残業代の扱いが不明瞭 |
| 実質時給の妥当性 | 30点 | 地域別の業種相場との比較 |
| 年間休日数 | 25点 | 就労条件総合調査の分布に基づく位置づけ |
| 残業・固定残業のリスク | 25点 | 固定残業時間、営業手当、裁量労働制 |

点数とは別に、次の場合はランクの上限を設けています。

- 最低賃金を下回る、または所定労働時間が法定を超える場合 → 「要注意」まで
- その地域・業種の相場自体が最低賃金に近い場合 → 「やや良好」まで

配点の根拠と算出式は、ソースコード内のコメントに記載しています。

## データの出典

| 用途 | 出典 |
|---|---|
| 業種別の賃金相場(20〜24歳) | 厚生労働省「令和7年賃金構造基本統計調査」第5-1表 産業、年齢階級別賃金 |
| 都道府県別の地域補正 | 同調査 参考表2 男女計の都道府県、産業別所定内給与額 |
| 年間休日数の分布 | 厚生労働省「令和7年就労条件総合調査」第4表 年間休日総数階級別企業割合 |
| 都道府県別最低賃金 | 厚生労働省「地域別最低賃金の全国一覧」令和7年度 |

## 更新について

- **最低賃金**:毎年10月から順次改定されます。発効日は都道府県ごとに異なり、令和7年度は栃木の10月1日から秋田の翌年3月31日まで半年近い幅がありました。そのため年度で一括せず、発効日ごとに有効な額を選ぶ構造になっています
- **賃金構造基本統計調査**:毎年3月頃に前年分が公表されます
- **就労条件総合調査**:毎年公表されます

年2回程度の更新サイクルを想定しています。

## 対応業種

日本標準産業分類の大分類に沿って15業種に対応しています。

学術研究・専門技術サービス業(コンサル・研究・士業) / 金融業・保険業 / 情報通信業(IT・Web・通信) / 不動産業・物品賃貸業 / 電気・ガス・熱供給・水道業 / 建設業 / 医療・福祉 / 運輸業・郵便業 / 卸売業・小売業 / 教育・学習支援業(学校・塾) / サービス業(人材派遣・警備・ビルメンテナンスなど) / 生活関連サービス業・娯楽業(美容・旅行など) / 製造業 / 宿泊業・飲食サービス業 / 複合サービス事業(郵便局・農協)

次のものには対応していません。

- **農業・林業・漁業、公務**:賃金構造基本統計調査の当該集計に含まれないため
- **鉱業・採石業・砂利採取業**:標本が少なく、都道府県別の数値が0.59〜1.71倍と極端にばらつくため除外
- **事務職などの職種**:産業分類ではなく職種のため、産業別統計から相場を引けません。今後の対応課題としています

## ホーム画面に追加できます

PWA(プログレッシブウェブアプリ)に対応しています。スマートフォンでホーム画面に追加すると、アドレスバーのない全画面で起動し、電波がない場所でも採点できます。

- **iPhone / iPad**:Safariで開き、共有ボタン → 「ホーム画面に追加」
- **Android**:Chromeで開き、メニュー → 「アプリをインストール」または「ホーム画面に追加」

判定基準を更新した場合は、次に開いたときに画面上部へ更新の案内が出ます。

## 技術構成

依存パッケージのないHTMLファイル1つで動作します。ビルド手順もサーバーも不要で、`index.html` をブラウザで開けばそのまま動きます。

Service Worker はHTMLを通信優先、アイコン類をキャッシュ優先で扱います。統計データを年2回更新する都合上、キャッシュに古い判定基準が居座らないことを優先した構成です。

### データを更新するときの手順

1. `index.html` 内の該当テーブル(業種別基準時給、最低賃金)を更新する
2. **`sw.js` の `CACHE_VERSION` を必ず上げる**(例:`v1-2026-09` → `v2-2027-03`)
3. コミットして反映する

`CACHE_VERSION` を上げ忘れると、すでにホーム画面に追加した利用者の端末で古いキャッシュが残り続けます。
